<CaseStudyScroll id="knight-capital-2012" />

In 2012, Knight Capital, one of the largest trading firms in the United States, deployed new software. A stale configuration flag on one server meant old code started firing live orders into the market.

In **45 minutes**, the firm lost **$440 million** and never recovered as an independent company.

The models were fine. The maths was fine. The *data feeding the machine*, one flag, on one server, was wrong.

<Callout type="danger">
This is the pattern across finance: **most analytics failures are data failures wearing a model's clothes.**
</Callout>

So before you write a single line of Python, this module teaches you to interrogate data like a professional. What is it? Where did it come from? Can it be trusted? What is it hiding?

**By the end of this module** you'll be able to look at any dataset and produce a *Trust Report*, with no code at all.
